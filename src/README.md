# KWM Systems website: how it's built

The KWM pages are plain static HTML, generated by a small zero-dependency Node script and committed, because Hostinger deploys this repo as-is. Nothing here needs `npm install`. (This folder is blocked from the web by `src/.htaccess`.)

```
node src/build.mjs              # writes every KWM page + sitemap.xml, prints the owner to-do list
node src/build.mjs --faq-doc    # also writes ../launch-pack/07-customer-faqs-and-workflows.md
node src/check.mjs              # checks links, anchors, assets, one h1, ids, meta, alt text, labels
PORT=8330 node src/serve.mjs    # preview at http://localhost:8330/ (forms say "preview, nothing sent")
node src/shot.mjs http://localhost:8321/ home.png 390 844 --mobile --full   # screenshot with installed Chrome
```

## Where things live

| What | File |
|---|---|
| Business facts (email, company number, office), nav, owner to-do list | `src/content/site.mjs` |
| **Prices, allowances, top-ups, Business OS "from" prices, policies** | `src/content/pricing.mjs` |
| Every service's copy, steps, examples, boundaries, FAQs | `src/content/services.mjs` |
| Page shell (head, header, menu, footer) | `src/templates/layout.mjs` |
| Components (the slip, day strip, phone, price boxes, FAQ, enquiry form) | `src/templates/components.mjs` |
| Logo mark and icons | `src/templates/icons.mjs` |
| Pages | `src/pages/*.mjs` (home, web, solutions, business-os, landing, pricing, about-contact, legal, notfound) |
| Styles | `css/kwm.css` (tokens at the top) |
| Script | `js/kwm.js` (menu, tabs, enquiry forms, Business OS calculator) |
| Fonts (self-hosted, OFL) and images | `assets/kwm/` |

Pages built: `/`, `/websites/`, `/work/`, `/solutions/` (the services hub) with the AI receptionist, website enquiry setup, Local Business Refresh and social media pages, `/business-os/`, the six advert landing pages, `/pricing/`, `/about/`, `/contact/`, `/privacy.html`, `/terms.html` and `/404.html`.

## Untouched King Media files

The following still use the King Media design and `css/style.css`:
- `websites-for-*/` and `small-business-websites/`: the Google Ads landing pages
- `concepts/`
- `api/`: forms, Stripe, contracts
- `js/main.js`, `js/lp.js`

Don't edit `css/style.css` for KWM changes.

## The enquiry form

It posts to the existing free question endpoint (`/api/submit.php`, `form=question`), the same route as the landing pages, so no server change is needed. Live, it emails `enquiries@kingmedia.uk`; the email's header still says "King Media · New question" (a cosmetic change in `api/lib.php` if wanted). A successful send fires `km:lead` for the dormant Google Ads tracker in `js/track.js`.

## Releasing

1. Bump `VERSION` in `src/templates/layout.mjs`, so browsers fetch the new CSS and JS.
2. Run `node src/build.mjs` and then `node src/check.mjs`.
3. Commit as **King Media <enquiries@kingmedia.uk>** (never a personal identity), push to `K111233/King-Media` main. hPanel deploys main automatically (Auto-deployment is on for the kingmedia.uk website); use Redeploy there if it doesn't. kwmsystems.com is a parked domain on that website, so both addresses update together.

Only do this once the owner has approved the decisions in `../launch-pack/00-HANDOFF.md`.
